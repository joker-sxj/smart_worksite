## 4. 第三阶段交互验收

- 回答完成后自动展示最多 3 个延伸问题，不依赖用户先点击“继续追问”。
- 点击延伸问题后，问题立即进入当前对话并触发下一轮本地模型生成。
- 点击后按钮进入“已提问”/禁用状态，重复点击不会产生重复消息。
- 刷新页面后，已点击延伸问题仍保持已提问状态。
- Java 与前端统一传递 `clientRequestId`、`sourceSuggestionMessageId`，支持幂等。
- 上下文改写、会话摘要和消息窗口均按会话隔离；长会话验证了 12 轮，主题切换不串会话。
- `SUCCESS + suggestionStatus=PENDING` 时前端继续轮询，避免回答已结束但延伸问题尚未显示。
