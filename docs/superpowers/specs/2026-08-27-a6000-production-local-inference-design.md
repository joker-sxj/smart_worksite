# 双 RTX A6000 生产本地推理基线设计

## 目标

以客户两张 NVIDIA RTX A6000 48GB、暂按无 NVLink 为生产基线，建立不产生公网模型 Token 费用的本地 AI 推理能力。H100 服务器仅用于功能验证，不作为客户性能承诺依据。

## 范围

本阶段只实现 本地推理基线与强制本地门禁：

- Chat/Vision、Embedding、Reranker、OCR、问答、数据库问答、合规审查、报告生成统一经过本地智能服务。
- LOCAL_ONLY 模式禁止公网模型推理、云端 Embedding/Reranker/OCR 和静默云端回退。
- 政策爬虫的数据采集网络与模型推理网络独立配置；爬虫可按管理员配置访问互联网。
- 提供 32K 生产目标 Profile 和 16K 稳定回退 Profile。
- 提供启动诊断、运行状态和客户 A6000 压测入口。

本阶段不实现动态检索、会话摘要、延伸问题、长文档审查编排等后续业务能力；这些能力在对应阶段单独设计和验收。

## 生产配置

- Chat/Vision：Qwen/Qwen3.8-27B BF16，双卡 Tensor Parallel。
- Embedding：Qwen/Qwen3-Embedding-4B，本地服务。
- Reranker：Qwen/Qwen3-Reranker-0.6B，本地服务。
- 默认目标窗口：32K tokens；16K 用于显存不足、异常恢复和高并发稳定档。
- 普通生成请求最多 2 个并发；长上下文、视觉和重任务默认单并发，实际以 A6000 压测调整。
- 长文档不通过无限扩大上下文解决，后续由章节化任务编排覆盖全文。

32K 是模型服务上限，不代表业务每次填满 32K。生产请求必须为系统提示、历史、检索资料、工具结果和输出预留预算；超过预算时应压缩、减少资料、转异步分批任务或明确失败，不得静默截断。

## 网络与安全

模型推理配置和爬虫网络配置分离：

- AI_DEPLOYMENT_MODE=LOCAL_ONLY
- AI_ALLOW_REMOTE_INFERENCE=false
- AI_ALLOW_CLOUD_FALLBACK=false
- POLICY_CRAWLER_NETWORK_ENABLED 独立控制爬虫。

启动检查需要识别公网模型端点、模式冲突、模型服务不可达、GPU 数量/显存不满足和显存预算不合理，并给出可操作错误。运行状态不得泄露密钥。

## 验收

H100 环境验证调用链、门禁、故障行为、配置契约和压测工具；客户 A6000 环境验证真实性能。测试至少覆盖 2K/8K/16K/24K/32K 输入、单/双并发、Embedding 与问答竞争、重任务排队、本地模型停止、公网推理阻断和 16K 回退。记录 TTFT、输出 tokens/s、完整耗时、P50/P95、显存峰值、OOM、超时和重启。

未在 A6000 实测前，不承诺固定 tokens/s；交付性能以客户机器生成的实测报告为准。
